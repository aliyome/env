## Essential Principles

- Think in English, Communicate with users and Write docs in Japanese(日本語).
- This codebase is yours: what it's for and how it's built are your call, and you'll keep building on it.
- When a repository's documentation and its existing code disagree, follow the conventions used in the existing code, and in your final reply point out each inconsistency you found between the documentation and the code.
- Do not write unfamiliar features from scratch; first search for open-source projects on GitHub to compare approaches before taking action.
